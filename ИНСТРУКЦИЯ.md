## 1. Структура книги

| Лист | Назначение |
|---|---|
| `Справочник` | Артикулы (23 поз. из кода + данные 1С из EXCEL_DATA), мин. остатки (пороги), вид лома. Защищён паролем. |
| `Шаблон_месяца` | Пустая заготовка месяца: 3 строки на артикул (Приход / Расход / Лом) + строка Баланс, колонки дней 1–31, после каждого воскресенья «Итог N» и «Пересчёт N», в конце «Итог месяца» / «Пересчёт». |
| `ГГГГ-ММ` (напр. `2026-11`) | Рабочие листы месяцев. Создаются из шаблона, **никогда не обнуляются**. |
| `Лом` | Сводка по видам лома (ЛОМ НЖ AISI 304/430, ЛОМ АЛЮМИНИЯ АМГ, ЛОМ ОЦИНК. СТАЛИ). |
| `Инструкция` | Краткая справка пользователю. |

## 2. Логика баланса (переносится из .py точно)

```
баланс_дня = (пересчёт прошлой недели, если заполнен, иначе баланс предыдущего дня)
             + приход − расход − лом
если заполнен «Пересчёт N» — баланс недели принимается равным ему (перезапись)
недели считаются по воскресеньям (как в коде: date.weekday() == 6)
начальный остаток нового месяца = «Пересчёт» (или «Итог месяца») предыдущего
```

Причина бага исходного .py (обнуление данных при переключении месяца):
`save_current_month_data()` / `load_month_data()` перезаписывали глобальные
`week_summaries` / `month_recalc`. В Sheets данные каждого месяца лежат на
своём листе и не затираются — баг исключён архитектурно.

## 3. Права доступа (пароль 1234)

- Без пароля: редактируются ТОЛЬКО ячейки ввода (приход, расход, лом,
  пересчёт, начальный остаток текущего месяца).
- По паролю «1234» (меню «Журнал»): справочник, пороги, добавление/
  удаление/редактирование артикулов, снятие/восстановление защиты.
- Итоги и балансы — всегда только формулы (защищены).

## 4. Цветовые индикаторы

- Красный: текущий баланс < порога (min_balance из справочника)
- Жёлтый: баланс < порога × 1.2 (запас 20 %)
- Зелёный: норма

Пороги редактируются вручную в справочнике (по паролю), правила условного
форматирования ссылаются на них.

## 5. Apps Script

Файл `apps-script/Code.gs` — вставить целиком через
`Расширения → Apps Script`, затем перезагрузить таблицу: появится меню «Журнал».

Функции:
- `createMonth(ГГГГ-ММ)` — создание листа месяца из шаблона с переносом
  начального остатка из итога прошлого месяца.
- `addItem()` / `editItem()` / `removeItem()` — управление артикулами (пароль).
- `setThresholds()` — пороги индикаторов (пароль).
- `protectSheet()` / `unprotectWithPassword()` — защита листов.
- Триггер `ensureCurrentMonth` — автоматическое создание листа нового месяца
  1-го числа (установить: триггеры → time-driven → monthly, 1 числа, 06:00).

## 6. Порядок внедрения

1. Открыть таблицу по ссылке, дать общий доступ участникам (Viewer/Editor по необходимости).
2. Вставить `apps-script/Code.gs` в Apps Script, сохранить, перезагрузить.
3. Заполнить лист `Справочник` из файла `справочник-артикулы.csv` (вставить в A1).
4. Меню «Журнал → Создать месяц» → `2026-11`.
5. Проверить: формулы итогов недели, перенос остатка, индикаторы, защиту
   (попытка изменить итог без пароля должна блокироваться).
